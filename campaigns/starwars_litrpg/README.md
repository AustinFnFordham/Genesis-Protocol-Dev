# Star Wars LitRPG

Persistent, player-driven LitRPG campaign in the Genesis Protocol setting. The AI runs the world, NPCs, factions, and the System. The player runs the protagonist (or party). Arcs become novel chapters.

| Folder | Visibility | Contents |
|---|---|---|
| `CAMPAIGN_CHARTER.md` | both | Locked rules and decisions. Read this first every session. |
| `characters/` | player-visible | Party sheets (only what the characters know). |
| `records/` | player-visible | Arc Records, session log, roll log, established canon. |
| `hidden/` | **GM only** | Hidden ledger: System mechanics, NPC motives, DCs, dice state. Spoilers. |
| `creator/` | both | Character creator work: audits, promoted canon examples. |

Dice: `.claude/skills/litrpg-dice/`.
